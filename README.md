# arena-sdk 0.3.0

What an external app imports from the Bitcoin Arena: `arena-sdk/manifest`, `arena-sdk/hash`, `arena-sdk/donation`, `arena-sdk/testnet4-donation-set-keys`, `arena-sdk/series`, `arena-sdk/encode`, `arena-sdk/display-name`, `arena-sdk/genesis-ids`, `arena-sdk/up-down`, `arena-sdk/manifest-sign`, `arena-sdk/ed25519`, `arena-sdk/known-games`, `arena-sdk/order-book`, `arena-sdk/contracts`, `arena-sdk/constants`, `arena-sdk/transcript`, `arena-sdk/sha256`, `arena-sdk/tick`, `arena-sdk/genesis`, `arena-sdk/ballot-chain`, `arena-sdk/batch`, `arena-sdk/host`, `arena-sdk/core-hash`.

In the app's package.json:

    "dependencies": { "arena-sdk": "github:george-prime/arena-sdk#v0.3.0" }

Packed from george-prime/bitcoin-arena (packages/arena-sdk, tools/pack.mjs). Change it there, not here.
